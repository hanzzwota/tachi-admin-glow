# User page entry points

User flows are exposed through extensionless routes: `/login`, `/register`, `/dashboard`, `/setor`, `/saldo`, `/profil`, and `/riwayat`. Each route now renders its own document from `public/pages/` (`login.html`, `register.html`, `dashboard.html`, `setor.html`, `saldo.html`, `profil.html`, or `riwayat.html`) inside the shared route frame. Shared styles, navigation, modal behavior, and API client are in separate public assets. Legacy root-level `.html` aliases redirect to their extensionless route. The server-side session continues to use an HttpOnly cookie; browser storage is not the source of account or transaction data.
